## About

This portfolio serves three purposes:

1. **Reflect** on my tutoring practice across Information Systems III and Technical Programming 2.
2. **Demonstrate** my web and application development skills through a hand-built, dependency-free site.
3. **Present** evidence of my tutoring work — session plans, attendance registers, assessment papers, digital activity logs, and student feedback.

It is structured around the eight required e-portfolio sections set out by the Sinawe Tutor Programme.
