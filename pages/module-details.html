02 Module Description

Information Systems III is a third-year module that focuses on developing students' knowledge and practical understanding of IT project management and database management systems.

The module is divided into two main learning units. The first focuses on IT Project Management, where students learn how IT projects are planned, managed, monitored, and completed. The second focuses on Database Management Systems, where students develop advanced knowledge of database design, SQL, transaction management, concurrency control, distributed databases, and data warehousing.

The module also provides opportunities for students to apply their knowledge through practical activities and a group project based on a selected business scenario. The knowledge gained in Information Systems III is intended to prepare students for solving discipline-related problems and applying ICT concepts in workplace environments.

03 Module Purpose

The purpose of Information Systems III is to equip students with a strong understanding of both IT project management and database design and implementation.

Students are introduced to important project management concepts such as project integration, scope, schedule, and cost management. The database component develops students' ability to design and implement databases using advanced data modelling techniques, SQL, transaction management, concurrency control, distributed database systems, and data warehousing.

04 Learning Outcomes

By the end of the module, students should be able to:

  1. Understand and apply IT project management principles, including project integration, scope, schedule, and cost management.
  2. Model business systems using Extended Entity Relationship (EER) models and apply advanced data modelling concepts.
  3. Apply database normalization principles to improve database structures and design.
  4. Design and implement databases using SQL, including complex queries, joins, views, stored procedures, functions, and triggers.
  5. Understand transaction management and concurrency control and explain how they contribute to maintaining database integrity.
  6. Understand Distributed Database Management Systems (DDBMS) and how distributed databases are designed and managed.
  7. Understand data warehousing and decision-support systems and apply concepts such as OLAP, star schemas, and snowflake schemas.

05 Topics Covered

Unit 1

IT Project Management

The first learning unit covers:

  • Introduction to Project Management
  • IT Project Management and the IT Context
  • Project Management Process Groups
  • Project Integration Management
  • Project Scope Management
  • Project Schedule Management
  • Project Cost Management
  • Project Management software
  • Work Breakdown Structures (WBS)
  • Gantt Charts
  • Network Diagrams
  • Critical Path Analysis
  • Earned Value Management
  • Agile and predictive project management approaches

Students are also expected to apply project management concepts to their group projects and use appropriate project management tools where required.

Unit 2

Database Management Systems

The second learning unit covers several advanced database concepts:

Advanced Data Modelling

  • Extended Entity Relationship (EER) Models

  • Primary keys and surrogate keys

Database Normalization

  • Normalization concepts
  • First Normal Form (1NF)
  • Second Normal Form (2NF)
  • Third Normal Form (3NF)
  • Boyce-Codd Normal Form (BCNF)

Advanced SQL

  • Complex SQL queries
  • Joins
  • Grouping and functions
  • Views
  • Indexes
  • Stored procedures
  • User-defined functions
  • Triggers

Databases and Application Development

  • Creating databases and tables
  • Creating keys and indexes
  • Retrieving and modifying data
  • SQL programming
  • Stored procedures
  • User-defined functions
  • Triggers
  • Data connectivity

  • Database backup and recovery

Transaction Management & Concurrency Control

  • Database transactions
  • Transaction properties
  • Transaction logs
  • Concurrency problems
  • Locking methods

  • Timestamping methods

Distributed Database Management Systems

  • Distributed databases
  • Distributed processing
  • DDBMS components
  • Data and process distribution
  • Distributed transparency
  • Distributed transactions
  • Data fragmentation
  • Data replication

Data Warehousing

  • Decision Support Systems
  • Data warehouses

07 My Responsibilities as a Tutor

As a tutor for Information Systems III, my responsibility is to provide additional academic support to students and assist them in developing a better understanding of the module content.

My responsibilities include:

  • Preparing and conducting tutorial sessions based on the module content and students' learning needs.
  • Explaining difficult concepts in a simple and understandable manner.
  • Assisting students with IT project management concepts and practical activities.
  • Supporting students with database concepts such as EER modelling, normalization, SQL, transactions, and concurrency control.
  • Providing practical examples and exercises that allow students to apply theoretical concepts.
  • Helping students prepare for assessments through revision activities, practice questions, and discussions.
  • Assisting students with challenges related to their group projects, while encouraging them to develop their own solutions.
  • Following up on students' progress and identifying areas where additional academic support may be required.
  • Encouraging active participation during tutorials and creating an environment where students feel comfortable asking questions.
  • Using appropriate technology and digital resources to make tutorials more interactive and engaging.
  • Providing constructive feedback to students to help them improve their understanding and academic performance.

As a tutor, I also recognise that my role is not to replace the lecturer, but to provide additional support that complements the formal teaching of the module. My aim is to help students become more confident, independent, and capable of applying the concepts they learn in Information Systems III.
